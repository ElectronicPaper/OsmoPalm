# OsmoPalm v0.1.0-preview.1

First downloadable OsmoPalm preview for M5Stack Core2. This is a **prerelease, not stable v1.0**.
It packages the latest locally built firmware without changing its behavior or its on-device
identity, `7.9.1-return-icon`. Repository visibility remains private.

## Why not v1.0 yet?

Intermittent USB-unresponsive halts still have no established root cause. Fine-mode motion,
haptic comfort, long-running reconnection, and every camera action have not completed a
formal hardware acceptance pass. Focus commands remain experimental. A successful build
and regression suite do not remove these limitations.

## Included

Standalone camera discovery/pairing and Wi-Fi connection, HAND and JOG square control pads,
per-axis feel/easing, saved positions and transitions, bounded playback, recording controls,
persistent settings, and priority STOP. No computer or phone is required for standalone use.

## Camera compatibility

| Camera | Evidence and status |
|---|---|
| Osmo Pocket 4 Pro (4P) | Development-tested in this project: direct connection, telemetry and gimbal controls have been exercised. This does not certify every feature or every camera firmware. |
| Osmo Pocket 4 | Potentially compatible through the shared Pocket protocol and discovery path. **We have not tested it.** Pairing, control, telemetry and camera functions are unverified. |
| Osmo Pocket 3 | Potentially compatible through the shared Pocket protocol and discovery path. **We have not tested it.** Pairing, control, telemetry and camera functions are unverified. |

The compatibility inference comes from the existing three-model discovery path and
[upstream protocol work](https://github.com/erik-sutton95/OpenPocketCine).
An advertisement match or related project's support is not proof that OsmoPalm works.
Treat the exact camera model and camera firmware as part of every test result.
Core2 requires a 2.4 GHz camera Wi-Fi access point; a 5 GHz-only AP is not compatible.

## Downloads

- `OsmoPalm-v0.1.0-preview.1-firmware.bin`: application-only image, offset `0x10000`.
  Use only for an existing compatible OsmoPalm/Core2 partition layout.
- `OsmoPalm-v0.1.0-preview.1-core2-install.zip`: bootloader, partition table, boot-app data,
  application, manifests, flashing guide and available dependency license notices.
- `FLASHING.md`: first-install versus update instructions and safety boundaries.
- `manifest.json` and `SHA256SUMS.txt`: build identity and exact download hashes.
- Two labelled usage illustrations, also shown in the README.

## Verification ceiling

355 local offline tests passed; the existing source commit's GitHub clean Linux tests and
firmware build passed. The latest local image was rechecked with PlatformIO and esptool's
image checksum/digest validation. Firmware source tree:
`e79b7d781eaaa606bc7e096e82cf37700dc0a8c9`, built from
`d3d2074ababb59d2c695abb0bf05b2b22a3c26b0`.
This release adds documentation and illustrations, not firmware changes.

No new camera pairing, gimbal movement or device flashing was performed to publish this
release. Historical Pocket 4 Pro operation and earlier boot checks are not a fresh hardware
acceptance result for these downloadable bytes.
